# Officers

## Running events

Create and edit events from the website's [Officers page](https://sidequest-guild.com/officers/).
Each one gets its own Discord event and sign-up thread automatically, so you only make it once.
A change on the website reaches Discord within about 15 seconds, and a change in Discord reaches
the website at once.

## Attendance

Mark who came on the Officers page. Anyone who spent enough time in the event's voice channel is
ticked already; you only need to adjust it when someone attended without using voice. Attendance
feeds the Hall of Heroes, badges, and Renown, so one correction updates all of them.

## Recruiting

Applicants and trials show up on the Officers page, where officers vote yes or no. The addon's
Console also has a Recruits tab for the same list while you're in game.

## Confirming members

When someone is on the in-game roster but hasn't been confirmed yet, a Game Master can confirm
them from the website or the addon's Console Roster tab. Confirming someone gives them the
*New Arrival* role and opens the rest of the guild's Discord channels.

## The Discord bot

The bot, Game Master, has slash commands for picking channels, running the weekly events board,
moderation, leveling, and role menus. See the full command table on its
[developer page](developers/bot.md).

## Running a raid night with the addon

The addon's Console walks you through a raid night step by step: prep, invite, start recording,
then loot and bidding as the raid goes, then end raid. Boss kills and points are recorded as they
happen. The full walkthrough, including the loot bidding rules, is on the
[addon's developer page](developers/addon.md).

### Syncing a raid night to the website

After the raid, send the record to the website from
[the sync page](https://sidequest-guild.com/officers/sync/). You can paste the addon's export
text, upload its save file, or let `sidequest-sync` upload it for you automatically. Details for
all three are on the [addon's developer page](developers/addon.md).
